Use a deep near-black navy canvas with a subtle blueprint grid and faint abstract API schema structure. Place one restrained cyan route line through a few small nodes on the right half. Use crisp editorial, vector-like artwork with generous clean negative space on the left. Use no text, letters, numbers, logos, Go gopher, watermark, or busy detail.
